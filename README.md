# Projet Befunge - Détection du caractère 'a'

## Langage choisi
- **Nom :** Befunge-93 / Befunge-98
- **Page Esolangs :** [https://esolangs.org/wiki/Befunge](https://esolangs.org/wiki/Befunge)

## Interpréteur / Compilateur
- **Outil utilisé :** `cfunge`.
- **Lien Git :** https://github.com/VorpalBlade/cfunge
- **Commande de lancement :** `cfunge p.bf`.

## Points ouverts du langage
- **Taille des cellules :** Préciser la taille (souvent des entiers signés ou non, gérant les codes ASCII).
- **Débordement (Overflow) :** Comportement en cas de dépassement de capacité des cellules.
- **Fin d'entrée (EOF) :** Comportement de l'instruction de lecture de caractère (`~`) lorsqu'on atteint la fin du flux (renvoie généralement -1 ou 0 selon l'interpréteur).
